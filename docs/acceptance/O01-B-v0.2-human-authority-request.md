## Human signature and publication

The reviewing human saves each unsigned object locally and runs:

```bash
python scripts/sign_gate7_o01_campaign_decision.py \
  --input <unsigned-decision.json> \
  --github-login LowToHi
```

The resulting complete object must be posted by the reviewing human as a single fenced `json` block:

- `LEGAL` in issue `#124`;
- `PRIVACY_DATA_RIGHTS` in issue `#125`.

The automation does not sign, approve or post either decision.
