# O01-C v0.3 — Exact telephone-field identifier remediation

## Decision

O01-C v0.2 cannot be executed successfully because its ephemeral contact projection contains the unsupported TED Search API field `buyer-tel`.

The bounded diagnostic in PR #141 proved:

```text
buyer-tel                                   HTTP 400
organisation-tel-buyer                      HTTP 200
full v0.2 contact projection                HTTP 400
full projection with canonical replacement  HTTP 200
start/end controls                          HTTP 200 / HTTP 200
```

No contact values or raw responses were retained. The diagnostic used 11 requests against one fixed TED backend address and remained outside campaign evidence and public claims.

## Sole experimental delta

```text
/fields/ephemeral_contact_projection/3

from  buyer-tel
to    organisation-tel-buyer
```

The array length and every other field remain unchanged.

The following metadata changes only identify the new version:

```text
schema_version  v0.2 -> v0.3
campaign_id     AX-LIB-O01-TED-QALAG-ML-CONTROLS-v0.2
                -> AX-LIB-O01-TED-QALAG-ML-CONTROLS-v0.3
```

## Delta-contract architecture

The v0.3 authority surface does not duplicate the complete v0.2 contract. It binds:

1. the immutable v0.2 base-contract digest;
2. a content-addressed v0.3 delta contract;
3. a deterministic materialisation algorithm;
4. the exact diagnostic artifact and result digest;
5. an exact Git target head and tree.

The verifier rejects any changed JSON pointer outside:

```text
/schema_version
/campaign_id
/fields/ephemeral_contact_projection/3
```

Only the third pointer is experimental.
