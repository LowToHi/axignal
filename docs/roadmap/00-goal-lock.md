# 00 — AXIGNAL Goal Lock

Version: `0.4.0`

Goal ID: `AXIGNAL-GOAL-001`
Governing contract candidate: `31`
Decision: `ADR-016`

## 1. Locked goal

AXIGNAL MUST become a premium, global and multilingual **Opportunity Intelligence & Operations environment** in which professional teams can discover, investigate, compare, monitor and operate economic opportunities through a governed world model and persistent workspaces built from traceable claims, evidence, contradictions, time and outcomes.

AXIGNAL MUST combine:

```text
GLOBAL OPPORTUNITY INTELLIGENCE
+ EVIDENCE-GOVERNED INVESTIGATION
+ OPPORTUNITY OPERATIONS
```

The product MUST preserve the complete path:

```text
signal
→ admitted evidence
→ Candidate Claim
→ deterministic admission
→ InvestigationContext
→ Opportunity
→ Pursuit
→ Operational Workspace
→ Outcome
→ Learning
```

A product that stops at search results, alerts, generated prose, Candidate Claims, recommendations or dossiers is incomplete.

## 7. Product invariants

### 7.1 Claims, not generated prose, are authoritative

Generated explanations may navigate and explain canonical state. They MUST NOT silently create canonical facts, source admission, opportunities, entitlements, publication state or scores.

### 7.2 Intention guides research, not truth

User interest may form a behavioural observation and an aggregate Knowledge Tide. It MUST NOT serve as direct evidence that an economic opportunity exists.

### 7.3 Globe and Graph are equal lenses

Globe and Graph MUST operate on the same `InvestigationContext`, claims, timeline, entitlements, pursuit and evidence rail.

Neither may become decorative or reduced-function.

### 7.4 Explicit user choice prevails

Lens priority:

1. explicit user choice;
2. geographical intent → Globe;
3. relational, ownership, transmission or causal intent → Graph;
4. temporal intent → current lens plus Timeline;
5. evidence question → current lens plus Claim and Evidence Rail;
6. hybrid query → bounded AUTO may select Globe, Graph or Dual and MUST explain the choice.

### 7.5 Coverage absence is not negative evidence

Unavailable, unlicensed, stale or missing data MUST be represented as unknown or uncovered, never as zero opportunity.

### 7.6 Contradiction is first-class

Supporting evidence, contradictions, uncertainty, expiry and missing knowledge MUST remain visible.

### 7.7 Multilingual does not mean lossy translation

The system MUST preserve original source, language, canonical semantics, translation method and localised rendering separately.

### 7.8 Opportunity Operations is mandatory

AXIGNAL MUST retain active work through collaboration, evidence, history, automation and learning. It MUST NOT create dependency by preventing export or obscuring customer-owned data.

### 7.9 Premium value comes from meaning and workflow

Visual scale, motion and depth MUST communicate geography, relationships, time, workflow or epistemic state rather than decoration.

### 7.10 Observation and decision preparation, not unlawful representation

AXIGNAL MUST NOT execute unrelated financial transactions, hold assets, guarantee outcomes, submit bids, sign, file or represent an organisation without an independently approved typed authority.

### 7.11 Lawful data only

Public visibility does not imply permission to collect, persist, transform, redistribute or train on data.

### 7.12 Identity and tenant authority are server-side

The browser cannot select tenant, membership, role, seat capacity, trial eligibility, Founder Admin status or publication authority.

### 7.13 Public discovery is governed

```text
dataset ≠ indexable page
generated page ≠ published page
traffic ≠ qualified buyer
AI citation ≠ endorsement
```

### 7.14 Engineering evidence is not product acceptance

```text
code exists
≠ engineering E2E pass
≠ canonical acceptance
≠ commercial availability
≠ public launch
```

## 9. Anti-goals

An implementation MUST be rejected if it turns AXIGNAL into primarily:

- a chatbot returning unstructured prose;
- a tender-alert newsletter;
- a public-data mirror;
- a static dashboard collection;
- a map with decorative markers;
- a graph without operational workflows;
- a single opaque opportunity score;
- a system where user popularity proves truth;
- a mass scraper without rights governance;
- a monolingual product translated at the end;
- a platform whose core value can be replaced by a generic model prompt;
- a growth site with millions of low-value generated pages;
- a Founder Admin that simulates controls without server authority;
- a public partial product represented as finished.

## 10. Goal-loss tests

Before any phase gate, the agent MUST answer:

1. Does this change strengthen the path from global discovery to governed evidence and operations?
2. Does it preserve canonical claims and provenance?
3. Does it keep Globe, Graph, Timeline, Navigator and Opportunity Operations aligned?
4. Does it separate interest signals from economic evidence?
5. Does it work across the launch languages by architecture?
6. Does it strengthen differentiation from general AI?
7. Does it preserve decision preparation and typed human authority?
8. Does it have a lawful data, privacy and consent path?
9. Can it be disabled, rolled back or corrected while preserving evidence?
10. Is there evidence that it advances the current authorised engineering or canonical gate without conflating them?

Any `NO` or `UNKNOWN` blocks canonical acceptance unless the governing contract explicitly permits a bounded engineering exception.
