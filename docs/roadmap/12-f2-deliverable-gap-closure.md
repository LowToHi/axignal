# 12 — F2 Deliverable-Gap Closure

Version: `0.1.0`
Status: `EVIDENCE CANDIDATE`
Goal ID: `AXIGNAL-GOAL-001`

## Decision

F2 can move from `EVIDENCE_READY` to `GATE_REVIEW` only when this unit proves:

1. scheduler persistence, idempotency, lease recovery and dead-letter behavior;
2. object-store roundtrip, immutable addressing and hash rejection;
3. trace-context propagation with zero prohibited telemetry fields;
4. explicit process credentials, health, readiness, restart and concurrency limits;
5. clean-clone CI, migration replay and pre-050 snapshot restore.

## Non-goals

This unit does not authorise production deployment, continuous source crawling, OCR, billing, external identity, new models or a broader source universe.
