# AXIGNAL Visual Asset Source Admission

## Admissible sources for the landing foundation

- NASA Earth Observatory / Visible Earth for Earth imagery, subject to NASA media-use terms and recorded source pages;
- Natural Earth for public-domain vector and raster map data;
- AXIGNAL-owned SVG branding;
- AXIGNAL-created synthetic demo data and generated fallback artwork.

## Required record

Every external asset record includes source page, direct acquisition URL when stable, rights basis, intended use, original dimensions, local derivative path, transformation recipe, hash after acquisition, attribution requirement and kill switch.

## Prohibitions

Do not hotlink production assets, scrape commercial map tiles, use unlicensed cloud textures, include disputed boundaries without a declared policy, or present generated geography as cartographically accurate.
